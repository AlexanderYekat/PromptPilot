завершённые задачи серии 4 по `started_at`, provider metadata в `result`.

23 запуска без продвижения до последнего recovery: 43 825 144 входных токена,

18 175 395 входных токенов (17 329 280 cached), 112 627 выходных;
55,8 минуты. Последний task #2103 не включён в «без продвижения»:
он снял устаревший ship и оставил диагностический комментарий.

Денежная стоимость не записана: `/api/stats/costs` отдаёт нули, но это не
доказательство бесплатности. По этому журналу нельзя вычислить списание
подписочных лимитов или стоимость в рублях. Cached input уже входит в input,
а reasoning output — в output: складывать их повторно нельзя.

Причина зацикливания: исходный review-proof #1505 не соответствует epoch
после pp:review-again, но single-flight repeatedly отправлял ту же цель в
полный fallback. Circuit breaker сравнивал текст итоговой причины; агент
перефразировал один отказ, и два HUMAN_REQUIRED не считались повтором.

Исправление: два подряд явных human-handoff для одного однозначного #N
приостанавливают настроенную pipeline-серию независимо от формулировки.
Отказы UNABLE, разные номера и неоднозначные multi-target причины сохраняют
старое текстовое сравнение. Resume остаётся явным действием оператора.
Регрессионный тест воспроизводит итоговые строки задач #2096 и #2098 через
штатный цикл completion → worker recurrence, без живого GitHub.
